Block picker

Block guide

Use the category buttons at the picker’s left edge to switch block groups. Drag blocks onto the canvas or click to add them. In this HTML, add one entry to const blocks to add a block, delete its entry to remove it, and set kind to a category id in blockCategories.

Stacks

Each stack is its own independent script and becomes its own section in main.lua. Click a stack to make it the target for clicked blocks, drag blocks between stacks, or drop a block on empty canvas to start a new stack. Use ◀ ▶ to reorder, ⧉ to duplicate and ✕ to delete.

Blocks that return a value (pink value blocks, getters, Lua math/text/operators, enums, fields) can be dragged into any input. Value blocks clicked on their own become a Set variable block. Getters also have a “save as” box to store their result in a variable.

Saving and exporting

“Save project (.json)” keeps everything (blocks, Lua, files) and “Load project” brings it back. “Export mod folder” writes ModName/ with main.lua and your files into a folder you choose, such as the game's mods folder. “Export zip” downloads the same thing as a zip. Add models, icons and other files in the Files tab.

The available API depends on the game version. Check the game's trailmakers_docs.lua file when adding advanced behavior.

Variables and text can be combined with the merge reporter. UI blocks generate the same tm.playerUI calls used by Trailmakers mods.

How this works
This is the folder that gets exported. main.lua is always generated from your blocks or the Lua editor. Drag files in from your computer, drag rows onto folders to organise, and new uploads land in the selected folder.
The game reference reads static files from the mod's data_static directory, and DoFile takes a name without .lua and no subfolders. 
Meshes and textures: Add mesh and Add texture blocks suggest your uploaded file paths. Check in game which path form it expects.
Files are stored in this browser. “Save project (.json)” embeds them so nothing is lost; “Export zip” or “Export mod folder” gives you the finished mod.
